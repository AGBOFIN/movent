# Design system MOVENT

| Jeton | Valeur | Usage |
|---|---|---|
| Midnight Navy | `#10172A` / `#0E1426` | Couleur principale, en-têtes, fonds sombres |
| Royal Violet | `#7057E8` | Boutons et actions |
| Champagne Gold | `#D6AE69` | Accent premium, boutons principaux |
| Soft Background | `#F6F7FB` | Fond des espaces de travail |
| White | `#FFFFFF` | Cartes et surfaces |
| Slate | `#64748B` | Textes secondaires |
| Success / Danger | `#16A36A` / `#DC5555` | Confirmations / erreurs et rejets |

Typographies : **Anton** (titres vitrine), **Plus Jakarta Sans** (titres, navigation, boutons), **Inter** (textes, formulaires, tableaux).
Règles : rayons 12 à 16 px, boutons ~48 px, espacements en multiples de 8, ombres légères. Maquettes de référence : desktop 1440×1024, tablette 768×1024, mobile 390×844.
Page d'accueil : `frontend/overlay/resources/views/welcome.blade.php` + `public/css/landing.css`.
